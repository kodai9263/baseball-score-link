# 公開準備

確認日：2026-09-12。`main`へマージし、`https://baseball-score-link.vercel.app` で本番公開済みです。

## 現在の範囲

- 紙スコア表示、走塁入力、複数試合保存、メンバー登録、通算・学年別・期間別の打撃成績。
- 初回のチーム・選手登録、メールリンクログイン、チーム招待、管理者・記録者・閲覧者、チーム別クラウド保存を実装済み。Supabase未設定なら同じ端末・ブラウザ・URL内に保存する。
- 全メンバー・試合をJSONに書き出せる。復元時は内容をプレビューし、現在のバックアップを書き出してから置き換える。不正なファイルは拒否する。
- 成績は入力済みの暫定記録から集計。代打・代走・守備交代・守備位置変更、開始前の先攻・後攻交換に対応。詳しくは [選手交代と先攻・後攻](lineup-changes.md)。公式記録判定、投手成績、再出場は未対応。
- 新しい試合で両チーム別にDHを選択できる。投手交代・DH解除・紙スコアへの反映は [DHの選択・交代](dh.md) を参照。先発投手兼DHなどの特殊方式は対象外。

## 本番接続の状態

チーム運用に必要な機能を実装し、本番のSupabaseへRLSと更新用RPCを適用した。公開URLと環境変数、認証後のRedirect URLも設定済み。標準SMTPの実メール受信と、複数アカウントによる本番権限・同期は [本番接続手順](cloud-setup.md) に沿って追加確認する。

## 公開後に残る確認

1. 実メールでログインし、認証後の保存・再読み込みを検証する。
2. 管理者・記録者・閲覧者の別アカウントで、権限と端末間同期を確認する。
3. 一般利用を始める前に独自SMTPと送信元を設定し、配信を確認する。
4. 開発URLから既存記録を移す場合は、JSONバックアップを保管して公開URLへ復元する。
