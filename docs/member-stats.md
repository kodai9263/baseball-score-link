# メンバー・試合・個人成績

2026-09-10実装。ログインしない場合は同じブラウザ・同じURL内に保存し、ログイン後はチーム別クラウド保存を使用する。

## 使い方

1. 「メンバー・成績」で名前を押す。現在打者の名前や紙スコアの選手名からも開ける。
2. 通算の打率・打席・打数・安打・本塁打・打点・得点を表示する。
3. 「今年度」「直近90日」または開始日・終了日と試合時の学年で絞る。年度は4月始まり、開始日と終了日を含む。
4. 学年別の表で比較し、試合別の内訳を押すとその試合のスコアに戻る。
5. メンバー登録・編集では名前、背番号、基準年度と学年、登録する側、守備位置、打席を設定する。
6. スコア入力の「新しい試合」で試合日、両チーム名、各側9人の打順を選ぶ。過去の試合は残り、表示する試合から切り替えられる。

## 集計と互換性

- 打率は安打合計÷打数合計。試合別打率の平均ではない。打数0は「—」。
- 四球、死球、申告敬遠、犠打は打数に含めない。失策出塁・野手選択は打数に含む。走塁イベントは打席・打数を増やさない。
- 試合数は打席・走塁などの記録、または交代で入った履歴が存在する試合を数える。先発選手の守備だけの出場は現状判定しない。
- 学年はメンバーの基準年度と試合日から計算し、その試合の選手情報として固定保存する。小学校1〜6年の範囲外は「学年不明」。
- メンバー情報を編集しても過去の名前・学年は変えない。試合情報の学年修正は、その試合だけに適用する。
- 旧保存は「日付未設定」の1試合として引き継ぐ。日付未設定は通算に含め、期間指定時は除外件数を表示する。
- バージョン2の試合帳へ保存する際にも旧保存キーは消さない。読込失敗・容量不足・他タブの変更で既存記録を上書きしない。

## 検証

115件の自動テスト、lint、型チェック、ビルド。実画面でメンバー登録→再読み込み、4年と5年の2試合作成・記録、通算.500、学年別1.000/.000、今年度・任意期間の抽出、期間逆転エラー、スコアへの移動、試合・集計の再読み込み、旧保存の引き継ぎを確認。375px幅で表示を確認した。

## 残る範囲

バックアップ出力・復元、クラウド同期、チーム管理は実装済み。先後攻の入れ替え、代打・代走・守備交代・守備位置変更は [選手交代と先攻・後攻](lineup-changes.md) を参照。先発の守備のみの出場、投手成績、犠飛など未対応の記録種別は別途必要。記録は暫定扱いで、本番版を公開している。

動作確認用のメンバー・複数試合はlocalhost側で作成し、127.0.0.1側の既存記録とは分けている。
