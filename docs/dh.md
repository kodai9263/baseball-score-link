# DHの選択・交代

2026-09-11実装。新しい試合の作成時に、両チームそれぞれ「使わない／使う（1〜9番）」を選ぶ。既存試合はDHなしのまま扱う。DH使用時は、打順9人とは別の投手を登録メンバーから選ぶ。

## 初期配置

指定した打順の選手をDHにする。その選手が元々野手の場合は、打順内の投手登録の選手がその守備を引き継ぐ。DH使用チームでは野手8位置が揃うことを検証し、重複した守備・打順内と同じ投手・相手チームの投手は拒否する。メンバーの登録情報と別試合の配置は変更しない。

試合開始後のDH追加は不可。先攻・後攻を交換した場合はDH設定と投手も一緒に交換する。

## 試合中

- DHへの代打・代走：通常の交代画面で入力。DHを引き継ぐ。
- DH使用中の投手交代：守備側を選び「DHを維持して投手交代」。打順やDHは動かさない。
- 投手がDHの代打・代走：DHの打席または塁上にいる間に「DH解除」から選ぶ。投手がDHの打順を引き継ぐ。走者も投手に替わり、生還は投手の得点として記録する。
- DHが守備につく：DHの打順は維持し、退く野手の打順へ投手を入れる。DH自身が投手になる場合は元の投手が退く。
- 投手と野手の守備交換：投手はDHの打順へ入り、DHが退く。野手は元の打順で投手になる。

解除前に変更後の配置を表示する。解除後のDH再使用は禁止。誤操作は通常の「取消」で戻せる。複数の配置変更を1件の履歴として保存・復元する。

## 紙スコア・成績

打順外の投手は打順「—」で別行に表示。DH解除で打順に入った投手は、その打順へ行を移し、同じ選手を二重表示しない。退いた選手の行は残す。打席・安打・得点は実際に記録された選手へ集計する。DH使用時の登録投手は、0打席でもその試合を出場試合数に含める。

## 対応範囲

通常の投手とDHが別選手の方式。先発投手兼DH（5.11(b)）、複数選手を同時交代して打順を指定するケース、臨時代走、リエントリーは未対応。先発DHの初打席完了や負傷による例外、投球数制限など、大会規定の交代資格は自動判定しない。画面上も大会ルールの確認を案内し、記録は従来どおり暫定扱いとする。

基本的なDH継続・解除の参照：[日本高野連の公認野球規則5.11解説](https://jhbf.or.jp/memberschool/regulation/dh/)。特定大会への全面準拠を示すものではない。

## 保存互換性・検証

試合帳v2の任意項目 `dh` に初期配置を追加し、投手交代・解除は既存の時系列交代履歴に追加する。旧データはそのまま読み込める。DHを含むバックアップの読み込みにはDH対応版が必要。

自動テストは全141件。両チーム独立設定、打者一巡、DHへの代打・代走、投手交代、3通りの解除、取消・復元、紙スコアの行重複防止、不正な保存データの拒否を検証する。

実画面は検証用の `localhost:3002` で両チームDHの試合を作成し、投手への代走変更・得点、守備へのDH解除、取消、投手交代、再読み込み後の保持を確認。375px幅の解除フォームとPC幅の設定フォームも確認済み。
